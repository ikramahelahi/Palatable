# Usability Testing Plan

This plan covers the features that are currently implemented in the front end. AI Chat is excluded because it is not functional yet.

Use task-based testing with a think-aloud protocol. Give the participant a goal, not instructions, and only step in if they are fully stuck. For each task, record the result and any notes as you observe.

## 1. Home Feed

| Feature | Function(s) to Test | Result | Notes / Comments |
| --- | --- | --- | --- |
| Friend review feed | - Scroll through the feed of friends' reviews<br>- Identify whose review is whose using avatar/name cues<br>- Tap a post to open the full review detail view | ☐ Pass ☐ Fail | |
| Post actions | - Like and save a post from the feed<br>- Open comments on a post<br>- Open notifications from the header | ☐ Pass ☐ Fail | |

## Notes For Moderation

- Ask participants to think aloud throughout each task.
- Measure whether they can understand the screen and complete the goal without help.
- Only step in if the participant is fully stuck.
- Record confusion points, incorrect assumptions, and any labels or controls that are easy or hard to interpret.
